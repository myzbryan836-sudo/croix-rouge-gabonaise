Configuration — synchronisation entre appareils

Par défaut, l'application fonctionne hors ligne et enregistre les signalements uniquement sur cet appareil. Pour que toutes les brigades partagent le même tableau de suivi, activez une base de données Supabase — service entièrement gratuit (offre Free, sans carte bancaire) pour ce volume d'utilisation.

  1. Aller sur supabase.com → créer un compte gratuit → New project.
  2. Une fois le projet créé, ouvrir l'onglet SQL Editor et exécuter :
    create table signalements (id text primary key, data jsonb, created_at timestamptz default now());
    puis :
    alter table signalements enable row level security;
    create policy "public rw" on signalements for all using (true) with check (true);
  3. Aller dans Project Settings → API. Copier l'URL du projet et la clé anon public.
  4. Coller les deux valeurs ci-dessous, au format indiqué.
